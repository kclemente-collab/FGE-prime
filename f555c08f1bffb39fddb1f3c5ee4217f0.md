# FGE Character System: Architecture Guide

## Overview
This document specifies the technical architecture for the Future Game Engine (FGE) Character System, leveraging Pydantic V2 for robust data provenance and automated redaction.

## Core Components
1. **BaseProvenanceModel**: Implements immutability via `frozen=True` and standardizes UTC timestamps.
2. **CharacterAnchor**: The identity root containing cryptographic hashes and internal developer notes.
3. **BuildGenome**: Aggregates anchors and traits with automated SHA-256 integrity checksums.
4. **CollectorPackage**: The top-level export wrapper that utilizes serialization context for automated privacy redaction.

## Context-Aware Redaction
The system differentiates between 'Internal Storage' and 'Buyer Export'. When `for_buyer` context is active, the system automatically:
- Strips `internal_notes`.
- Truncates `cryptographic_hash` to a 12-character preview.

## Data Integrity
Integrity is maintained via a computed checksum in the `BuildGenome` class, which ensures that any change to anchors or traits is detectable.
