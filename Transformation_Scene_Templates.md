# Transformation Scene Templates

These are reusable morph blueprints, acting as ritual sequences for cinematic DNA.

## Template 1 — "Pressure Ascent" (Human → Predator emergence)
- Frame 1: Stillness (baseline human)
- Frame 2: Micro-tension in skin
- Frame 3: Subdermal movement (barely visible)
- Frame 4: Bone structure begins shift
- Frame 5: Eyes change first (anchor moment)
- Frame 6: Facial distortion (controlled)
- Frame 7: Partial reveal (not full transformation)
- Frame 8: Hold tension (no release yet)

## Template 2 — "Glass Fracture" (Stylized transformation)
- Frame 1: Clean human face
- Frame 2: Light distortion across surface
- Frame 3: Skin behaves like glass
- Frame 4: Cracks form along emotion lines
- Frame 5: Internal form visible
- Frame 6: Outer shell breaks
- Frame 7: New form emerges through shards
- Frame 8: Reflection stabilizes

## Template 3 — "Organic Bloom" (Beauty → Creature hybrid)
- Frame 1: Soft beauty frame
- Frame 2: Texture shift (skin → organic)
- Frame 3: Color bleed
- Frame 4: Growth patterns (veins / fur / scales)
- Frame 5: Facial structure adapts
- Frame 6: Identity remains partially intact
- Frame 7: Full hybrid state
- Frame 8: Emotional lock-in

## Golden Rule (Seraphine enforced)
> "Transformation must feel earned, not triggered."
