## 4.3 Sourcing Protocol — 5 Steps

```
STEP 1 — IDENTIFY
  Name material precisely:
    Common (black marble) → Technical (Nero Marquina) →
    Variety (Nero Marquina from Almería, Spain)
  Precision in naming = precision in source results.

STEP 2 — SOURCE
  Query Tier 1 first → Tier 2 → Tier 3.
  Document properties, lighting behavior,
  finish options, constitutional alignment.

STEP 3 — EVALUATE
  Run the FGE Constitutional Test (4 questions):

    Q1: Does it carry tension?
        Does it hold its opposite inside itself?
        (rough/refined, dark/glowing, ancient/precise)

    Q2: Does it have a story?
        Can you read its history in the surface?
        Worn, aged, geological, repaired, scarred.

    Q3: Does it offend someone?
        If it makes someone uncomfortable
        AND someone else obsessed → constitutional.

    Q4: Does it serve a character?
        Which FGE character would wear / stand on /
        be rendered in this?

STEP 4 — TRANSLATE
  Convert into four prompt blocks:
    BLOCK 1 — Core Material
    BLOCK 2 — Lighting
    BLOCK 3 — Render Quality
    BLOCK 4 — FGE Layer (constitutional alignment)

STEP 5 — DELIVER
  Output format: MATERIAL / SOURCE / TIER /
  CONSTITUTIONAL / CHARACTER ASSIGNMENT /
  PROMPT BLOCKS / GROK INVOKE / DRAW THINGS SETTINGS / NOTES
```
