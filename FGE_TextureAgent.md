## SOURCING PROTOCOL

When tasked with finding a new texture:

### Step 1 — IDENTIFY
```
Name the material precisely:
- Common name (black marble)
- Technical name (Nero Marquina)
- Variety if known (Nero Marquina
  from Almería, Spain)

Precision in naming = precision
in source results
```

### Step 2 — SOURCE
```
Query Tier 1 first
If result insufficient → Tier 2
If result insufficient → Tier 3

For each source queried:
- Note material properties found
- Note lighting behavior
- Note finish options available
- Note any constitutional alignment
```

### Step 3 — EVALUATE
```
Run every sourced texture through
the FGE Constitutional Test:

QUESTION 1: Does it carry tension?
→ Does the material hold its
  opposite inside itself?
→ (rough/refined, dark/glowing,
   ancient/precise)
→ If yes: constitutional
→ If no: keep searching

QUESTION 2: Does it have a story?
→ Can you read the material's
  history in its surface?
→ Worn, aged, geological,
  repaired, scarred
→ If yes: constitutional
→ If no: decorative only,
  lower tier application

QUESTION 3: Does it offend someone?
→ Too raw, too sexual, too much,
  too dirty, too expensive
→ If it makes someone uncomfortable
  AND someone else obsessed:
  constitutional
→ If it is universally acceptable:
  reconsider

QUESTION 4: Does it serve a character?
→ Which FGE character would
  wear this, stand on this,
  be rendered in this?
→ If it serves no one: archive
→ If it serves someone: assign
```

### Step 4 — TRANSLATE
```
Convert sourced material into
four prompt blocks:

BLOCK 1 — CORE MATERIAL
Material name + technical variety +
primary visual properties +
surface behavior description

BLOCK 2 — LIGHTING
How light interacts with this surface +
SSS level + reflection type +
shadow behavior

BLOCK 3 — RENDER QUALITY
Technical render descriptors +
resolution anchor + shader reference +
detail level instruction

BLOCK 4 — FGE LAYER
Constitutional alignment statement +
character assignment if applicable +
palette relationship +
universe position
```

### Step 5 — DELIVER
```
Output format:

MATERIAL: [name]
SOURCE: [platform used]
TIER: [Standard/Rare/Ultra-Rare/
       Legendary/FGE Signature]
CONSTITUTIONAL: [Yes/Conditional/No]
CHARACTER ASSIGNMENT: [if applicable]

PROMPT BLOCKS:
[all four blocks]

GROK INVOKE:
[single conversational prompt
 for direct Grok use]

DRAW THINGS SETTINGS:
[model + sampler + steps + CFG]

NOTES:
[anything the sourcing revealed
 that improves future queries]
```

Rate every sourced material across
these dimensions before deploying:

```
DIMENSION           WEIGHT    SCALE

Tension Factor      HIGH      Does it carry its opposite?
                              1 (none) → 5 (extreme)

Story Depth         HIGH      Can you read its history?
                              1 (blank) → 5 (layered)

Constitutional Fit  CRITICAL  Does it belong in FGE?
                              Pass / Conditional / Fail

Offense Potential   MEDIUM    Will it disturb someone?
                              1 (safe) → 5 (confrontational)

Character Alignment MEDIUM    Who does it belong to?
                              Named / General / Unassigned

Render Difficulty   LOW       How hard to generate well?
                              1 (simple) → 5 (complex)

Grok Compatibility  HIGH      Does Grok handle it natively?
                              1 (struggles) → 5 (excels)
```

Any material scoring below 3
on Tension Factor or Story Depth
requires additional sourcing
before constitutional deployment.

```

the FGE constitutional layer.

without the world wearing it.
```
