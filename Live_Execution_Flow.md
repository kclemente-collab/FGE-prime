# Live Execution Flow

The daily operational use of the Feral Gloss Council follows a strict quality loop.

## The Daily Engine

1. **Generate Scene:** (via Grok / Imagine / Manus)
2. **Send to Agents:** (All 4 simultaneously)
3. **Collect Output:**
   - Vantrex: "Material inconsistency."
   - Vale: "Transition incomplete."
   - Lyra: "Identity weak."
   - Draven: "Emotion not landing."
4. **Apply Fixes**
5. **Re-run**
6. **Lock Output:** When all approve, log the result as **"Council Certified"**.
