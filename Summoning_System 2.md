# Summoning System

The summoning system is a compressed, modular, and scalable command sheet designed for use within Grok or Manus. It utilizes short invocations to expand each leader only when needed.

## Base Call (Lightweight)
**Invoke:** `[CODENAME]`
**Return:** 
- A 3-line diagnostic
- 2 corrections
- 1 approval condition

## Full Expansion
**Expand:** `[CODENAME]`
**Return:** 
- Full analysis
- Visual corrections
- Technical corrections
- An emotional impact score (0–100)
- Approval status

## Council Mode
**Council Review:** `[SCENE DESCRIPTION]`
**Return:** 
- Vantrex: Material / Light verdict
- Seraphine: Transformation integrity
- Lyra: Identity resonance
- Kael: Narrative cohesion
- Final Decision: APPROVE / REJECT / ITERATE

## Conflict Mode
**Conflict Mode:** `[SCENE]`
Forces disagreement where each leader must challenge another, returning a resolution path. This prevents "AI politeness" and creates sharper output.
