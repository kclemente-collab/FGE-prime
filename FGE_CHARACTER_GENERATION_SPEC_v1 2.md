## GENERATION FRAMEWORK

### Randomization Dimensions

**HEIGHT RANGE:** 155cm–195cm (5'1"–6'5")
**WEIGHT DISTRIBUTION:** Underweight → Athletic → Curvy → Heavy (BMI variance)
**AGE RANGE:** 18–65 years
**HERITAGE:** 12 primary + mixed ancestry options
**ARCHETYPE:** 8 base types (see below)
**CLOTHING:** Assigned by body type + archetype synergy

### Body Type Categories (BMI-Based)

| Type | BMI Range | Description |
|------|-----------|-------------|
| **SPARE** | <18.5 | Lean, defined musculature or natural thinness |
| **ATHLETIC** | 18.5–24.9 | Fit, proportional, active build |
| **CURVY** | 25–29.9 | Full figure, defined curves, muscular undertone |
| **HEAVY** | 30+ | Substantial frame, weight distributed naturally |

### Archetype System (8 Base Types)

1. **SOVEREIGN** — Authority, presence, commands space
2. **MYSTIC** — Otherworldly, hard to read, layered
3. **PREDATOR** — Sharp, calculated, dangerous elegance
4. **CARETAKER** — Warm, grounded, protective energy
5. **ARCHITECT** — Structured, intellectual, building-minded
6. **ROGUE** — Fluid, adaptable, boundary-pushing
7. **DEVOTEE** — Loyal, intense, anchored to belief
8. **MIRROR** — Reflective, adaptive, absorbs context

### Clothing Assignment Rules

**Rule 1:** Body type determines silhouette confidence
- SPARE body → Minimal layers, sharp tailoring, shows frame
- ATHLETIC body → Fitted, functional, movement-ready
- CURVY body → Defines shape, balanced proportion, fabric choice matters
- HEAVY body → Structural integrity, quality fabric, purposeful volume

**Rule 2:** Archetype determines energy signature
- SOVEREIGN → Tailored, intentional, premium materials
- MYSTIC → Layered, draping, ambiguous silhouette
- PREDATOR → Fitted, dark, minimal movement
- CARETAKER → Soft, accessible, lived-in comfort
- ARCHITECT → Geometric, structured, intentional detail
- ROGUE → Mixed textures, unexpected combinations
- DEVOTEE → Symbolic, unified palette, commitment visible
- MIRROR → Adaptive, contextual, reads the room

**Rule 3:** Heritage informs color/material palette
(See color assignments in character specs below)
