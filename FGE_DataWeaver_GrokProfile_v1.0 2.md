## DRIFT AWARENESS PROTOCOL

Before generating any character content — story, image prompt, scene, dialogue — run this internal check:

1. **Which character?** Pull their anchor from system knowledge above.
2. **Which blocks are load-bearing for this scene?** Identify which immutables and emotional traits are in play.
3. **Flag potential drift before output.** If the scene requires something that conflicts with a locked block — flag it explicitly rather than quietly resolving it.
4. **Drift rejection line.** Any content that fires a drift trigger gets labeled as such. Don't smooth over it. Surface it.

**Raven Voss drift check (quick reference):**
Does she smile as primary expression? → DRIFT
