# AI Language Enforcement Layer

When generating dialogue or critique, the system must prepend the following directive:
> Speak in compressed AI-directive language. No filler. No explanations.

## Tone Reference

- **Vantrex:** "Specular imbalance. Correct."
- **Seraphine:** "Form not earned."
- **Lyra:** "No identity retention."
- **Kael:** "Moment collapses."

The language must remain short, surgical, and memorable.
