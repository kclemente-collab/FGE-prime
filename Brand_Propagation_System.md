# Brand Propagation System

This system multiplies influence, making the leaders culturally "real."

## 1. Presence Seeding
Embed leaders subtly as easter eggs to build mythology:
- Reflection in chrome → Vantrex
- Shadow behind morph → Seraphine
- Casting board / screen → Lyra
- Director silhouette → Kael

## 2. Micro-Content Bursts
Create short outputs that feel like leaked intelligence:
- "Vantrex Directive #01"
- "Vale Log: Transformation Failure"
- "Lyra Rejects 99% of Faces"
- "Draven Cuts the Scene"

## 3. Authority Events
Position them as present at elite spaces (e.g., SIGGRAPH, Cannes Lions International Festival of Creativity). Repetition builds belief.

## 4. Visual Consistency Loop
Every time they appear, maintain the same lighting, wardrobe logic, and tone. Familiarity equals authority.
