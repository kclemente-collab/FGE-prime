- **Attributes → Name Mixer**: Produces unique, brandable names with IP tags
- **Processing Layers**: Modular wiring allows selective activation (e.g. skip deep intelligence for Tier 1)
- **Outputs**: Tiered products with built-in upsell (Micro → Module → Full)
- **Scalability Wiring**: JSON everywhere enables easy export, licensing, and external DB sync
