# FGE Character System: Pydantic V2 Architecture

This document outlines a production-grade schema architecture using **Pydantic V2**. It focuses on immutability, data provenance, and automated redaction for collector-facing exports.

## 1. Key Components

- **BaseProvenanceModel**: Enforces `frozen=True` and handles UTC-aware timezone serialization (Python 3.12+ compliant).
- **CharacterAnchor**: The cryptographic root of identity.
- **BuildGenome**: Aggregates anchors and traits, featuring a `computed_field` for data integrity checksums.
- **CollectorPackage**: The delivery wrapper that triggers redaction via serialization `context`.

## 2. Implementation

```python
from typing import Optional, List, Dict, Any, Union
from datetime import datetime, timezone
import hashlib
import json
from pydantic import (
    BaseModel, 
    ConfigDict, 
    Field, 
    field_serializer, 
    SerializationInfo, 
    computed_field
)

# --- 1. Base Architecture ---

class BaseProvenanceModel(BaseModel):
    """
    Base model enforcing immutability and UTC-aware serialization.
    """
    model_config = ConfigDict(
        frozen=True,
        validate_assignment=True,
        arbitrary_types_allowed=True
    )

    @field_serializer('*', when_used='json')
    def serialize_utc_datetime(self, value, info: SerializationInfo):
        if isinstance(value, datetime):
            return value.isoformat()
        return value

# --- 2. Identity & Anchors ---

class CharacterAnchor(BaseProvenanceModel):
    """
    Provenance lock recording original hashes and lock state.
    """
    anchor_id: str = Field(..., description="Unique provenance ID")
    cryptographic_hash: str = Field(..., description="Full hash of underlying asset")
    locked_at: datetime = Field(default_factory=lambda: datetime.now(timezone.utc))
    locked_by: str
    internal_notes: Optional[str] = None

    @field_serializer('internal_notes', 'cryptographic_hash', when_used='json')
    def redaction_logic(self, value, info: SerializationInfo):
        """Context-aware redaction logic."""
        context = info.context or {}
        if context.get("for_buyer", False):
            if info.field_name == "internal_notes":
                return None
            if info.field_name == "cryptographic_hash":
                return f"{value[:12]}..."
        return value

# --- 3. Genome & Traits ---

class GenomeTrait(BaseProvenanceModel):
    trait_type: str
    value: Union[str, float, int]
    rarity_score: float = Field(ge=0, le=1)

class BuildGenome(BaseProvenanceModel):
    """
    The assembly genome linking anchors and traits with integrity checks.
    """
    genome_id: str
    anchors: List[CharacterAnchor]
    traits: List[GenomeTrait]
    build_version: str = "2.0.0"

    @computed_field
    @property
    def genome_checksum(self) -> str:
        """
        Calculates a unique checksum using model_dump mode='json'.
        """
        content = self.model_dump(mode='json', exclude={'genome_checksum'})
        dump_str = json.dumps(content, sort_keys=True)
        return hashlib.sha256(dump_str.encode()).hexdigest()

# --- 4. Export & Packaging ---

class CollectorPackage(BaseProvenanceModel):
    """
    Top-level wrapper for buyer deliverables.
    """
    package_id: str
    genome: BuildGenome
    issued_at: datetime = Field(default_factory=lambda: datetime.now(timezone.utc))
    collector_id: Optional[str] = None

    def export_for_buyer(self) -> str:
        """
        One-click redacted export.
        """
        return self.model_dump_json(
            context={"for_buyer": True}, 
            indent=2,
            exclude_none=True
        )
```

## 3. Workflow Comparison

### Storage Mode (Full Data)
Maintains full hashes and internal developer notes for server-side persistence and provenance auditing.

### Buyer Mode (Redacted Data)
Automatically strips internal notes and truncates hashes, ensuring the collector receives a clean, professional manifest without leaking development internals.
