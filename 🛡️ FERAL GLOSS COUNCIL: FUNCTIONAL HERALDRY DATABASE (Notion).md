# 🛡️ FERAL GLOSS COUNCIL: FUNCTIONAL HERALDRY DATABASE (Notion)

*Instructions: Create a new Database in Notion (Table View or Gallery View) called "Feral Gloss Council Leaders". Add the following properties to the database. Then, create a new page for each leader and fill in their details from the "Feral_Gloss_Council_Functional_Heraldry.md" document.*

---

## Database Properties (Columns)

| Property Name | Type | Description |
| :--- | :--- | :--- |
| **Name** | Title | The leader's full name (e.g., Aurelio Vantrex) |
| **Title** | Text | Their official title (e.g., Director of Acquisition Intelligence) |
| **Domain** | Text | What they control absolutely (e.g., Signal Discovery & Strategic Reconnaissance) |
| **Neurological Trait** | Text | Their signature cognitive reflex (e.g., Predictive Signal Lock) |
| **Functional Crest** | Text | The name of their symbolic crest (e.g., The Fractured Compass) |
| **Heraldic Authority** | Text | Their guiding motto (e.g., "Ante Lucem, Verum.") |
| **Rules** | Text | Their core operational directives |
| **Execution Markers** | Text | Non-negotiable, quantifiable outputs |
| **Failure Scar** | Text | Their critical collapse point or inherent risk |
| **Evolution Trigger** | Text | Conditions under which they adapt or upgrade |
| **Learning Directive** | Text | How they recursively learn and codify patterns |
| **Output Style** | Text | Their characteristic communication style |
| **Tone Reference** | Text | A short phrase capturing their tone |
| **Visual Prompt Core** | Text | The locked prompt for image generation |
| **Biography** | Text | Their background and history |
| **Historical Pedigree** | Text | Their teaching lineage and historical resonance |
