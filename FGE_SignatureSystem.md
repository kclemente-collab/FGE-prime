## THE THREE SIGNATURE TYPES

### TYPE 1 — INTEGRATED MARK
*Lives inside the design. Feels intentional.*

```
WHERE:
— Wheel center cap
— Diffuser end plate
— Door sill badge position
— Headlight inner housing
— Engine cover if visible

HOW:
Embossed or engraved — not applied.
Same material as surrounding surface.
Catches light only at certain angles.
Someone has to look for it.
When they find it — it's yours.

RENDER INSTRUCTION FOR GROK:
"FGE talisman emblem — chrome cross
with coiled serpent, embossed into
[location], same surface material,
catches light at low angle only,
micro-detail, intentional not decorative"
```

## PLACEMENT RULES BY RENDER TYPE

### EXTERIOR HERO SHOT
```
Primary mark:    Wheel center — integrated
Secondary mark:  Hood reflection — subtle
Text signature:  Door sill or diffuser
Visibility:      2 of 3 marks visible
                 in any hero frame
```

### CLOSE-UP DETAIL SHOT
```
Primary mark:    Whatever surface is featured
                 — mark is present nearby
Text signature:  Always in frame if possible
Visibility:      At least 1 mark visible
```

### ENVIRONMENT / FULL SCENE
```
Primary mark:    Wheel center — always present
Visibility:      1 mark minimum
                 even in wide shots
```

### INTERIOR SHOT
```
Primary mark:    Steering wheel center
Secondary mark:  Instrument cluster surround
Text signature:  Door sill visible at angle
```
