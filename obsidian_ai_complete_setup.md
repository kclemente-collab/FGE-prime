## PHASE 2: PLUGIN INSTALLATION & SETUP

### Plugin 1: Smart Connections (Free Start)

#### Installation:
1. In Community plugins, search **"Smart Connections"**
2. Click **Install** → **Enable**
3. Click the **Smart Connections icon** in left ribbon

#### Configuration:
```
Settings → Smart Connections:
✅ Enable Smart Connections
✅ Show Smart Connections view
✅ Enable Smart View
✅ Auto-refresh: Every 30 seconds
✅ Minimum similarity: 0.25
✅ Max connections displayed: 10
```

#### Free Features You Get:
- Automatic note linking based on content similarity
- Smart search across your vault
- Connection visualization
- Note recommendations

#### Premium Upgrade ($5/month):
- AI-powered chat with your notes
- Enhanced connection algorithms
- Advanced filtering options

### Plugin 2: Text Generator Plugin (Requires OpenAI API)

#### Installation:
1. Search **"Text Generator Plugin"**
2. Install → Enable
3. Go to **Settings → Text Generator**

#### Get OpenAI API Key:
1. Go to **https://platform.openai.com**
2. Sign up/Login
3. Navigate to **API Keys** section
4. Click **Create new secret key**
5. Copy the key (starts with sk-...)
6. **Set usage limits** in OpenAI dashboard (recommend $5-20/month max)

#### Configuration:
```
API Settings:
├── API Provider: OpenAI
├── API Key: [paste your sk-... key]
├── Model: gpt-4o (best quality) or gpt-3.5-turbo (cheaper)
├── Max Tokens: 2000
├── Temperature: 0.7
└── Auto-suggest: Enable
```

### Plugin 3: Copilot Chat (Interactive AI)

#### Installation:
1. Search **"Copilot Chat"** or **"ChatGPT MD"**

#### Configuration:
```

├── API Key: [same key as Text Generator]
├── Model: gpt-4o
├── Stream responses: Enable
├── Save chat history: Enable
```

## TROUBLESHOOTING & SUPPORT

### Common Issues & Solutions:

#### Smart Connections Issues:
```
Problem: Not finding connections
Solution: Lower similarity threshold, add more tags

Problem: Too many irrelevant connections  
Solution: Raise similarity threshold, improve note structure

Problem: Slow performance
Solution: Exclude large folders, optimize vault size
```

#### Text Generator Issues:
```
Problem: API key not working
Solution: Check key format, verify billing setup

Problem: Poor quality output
Solution: Improve prompts, adjust temperature settings

Problem: High costs
Solution: Use shorter prompts, lower token limits
```

#### Copilot Chat Issues:
```
Problem: Chat not saving
Solution: Check folder permissions, verify chat folder setting

Problem: Slow responses
Solution: Use shorter context, check internet connection

Problem: Irrelevant responses
Solution: Improve prompt specificity, provide more context
```
