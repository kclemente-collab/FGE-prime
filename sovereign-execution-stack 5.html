Routing Logic

HOW REQUESTS
MOVE THROUGH THE STACK

✓ Clearance Protocol
01
Request enters at Warden. Lane type identified — Visual, System, Entity, or Batch.
02
Judge evaluates intent against doctrine. Confirms "Confirmed: Yes" before proceeding.
03
Architect receives cleared request. Selects template macro. Applies variable matrix (n, gloss, identity, pose).
04
3 variations generated in parallel — Clean / Balanced / Intense — each at full fractal compression.
05
Kael Draven runs Glamorama Stabilization Pass. Scores all 3. Winner identified. Failure reasons attached to losers.
06
Render Elite surfaces winner + alternates + Why This Won. Style Memory updated.
